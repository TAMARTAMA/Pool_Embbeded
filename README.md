# סקירת פרויקט Pool Embedded

המאגר מאגד מערכת משולבת לניטור בטיחות במתחם בריכה:

- **בקרי ESP32 / ארדואינו** (`DOFEK_32_ardouino`, `pool_ardouino`):
  - קוראים חיישנים כמו מד דופק MAX30105, מד טמפרטורה וחיישן גובה מים.
  - מדווחים על מצב בריאות השחיין (למשל חיפוש דופק, ירידה בטמפרטורת הגוף או אות חירום) ועל תנאי הבריכה לשרת המרוחק באמצעות תקשורת Wi-Fi.
  - מפעילים התקנים היקפיים כמו מנועים וסרווים לצורך בקרה פיזית בשטח.

- **שרת Node.js** (`pool_Server`):
  - מספק API לניהול משתמשים, קריאות חירום, רישום כניסות ועדכוני חיישנים.
  - מתחבר למסד נתוני MongoDB לשמירת המידע המתקבל מהבקרים ומהממשק.
  - משמש נקודת איסוף מרכזית לכל המידע המגיע מהמערכת המשובצת.

- **ממשק משתמש React** (`pool_UI`):
  - מציג לדיילי הבריכה ולמנהלי המערכת נתוני חיישנים בזמן אמת, התראות חירום והיסטוריית אירועים.
  - מאפשר שליטה והזנת מידע על משתמשים דרך דפדפן.

הפרויקט כולו נועד ליצור פתרון מקצה לקצה לניטור וניהול בטיחות בבריכה, משכבת החיישנים ועד הצגת הנתונים למשתמש הקצה.
